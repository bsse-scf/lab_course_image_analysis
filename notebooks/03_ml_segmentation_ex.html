Task 4: Cellpose, and the diameter#

Run Cellpose on the same image with diameter=None, then try several fixed diameters and see how much it matters.

Hint 1: the call 
from cellpose import models
model = models.Cellpose(model_type="cyto", gpu=False)
masks, flows, styles, diam = model.eval(image, diameter=None, channels=[0, 0])

The first import takes a while: that is normal.

Hint 2: what does diameter do?

It tells Cellpose how large it should expect objects to be, and it rescales the image accordingly. Too small and cells shatter; too large and neighbours merge.
