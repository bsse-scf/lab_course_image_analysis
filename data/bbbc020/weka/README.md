# Weka classifier and reference exports

## What is here

| file | produced by | used by |
|---|---|---|
| `bbbc020_cells.model` | Fiji, Trainable Weka Segmentation | `book/fiji/e4_weka.md` part 2 |
| `<field>_cells_probability.tif` | Fiji, **Get probability** | `notebooks/03_ml_segmentation.ipynb` |
| `<field>_cells_classified.tif` | Fiji, **Create result** | `notebooks/03_ml_segmentation.ipynb` |

for the three fields `15min_1`, `15min_2` and `24h_2`.

```{warning}
`bbbc020_cells.model` is trained interactively and **cannot be regenerated by any
script**. Do not delete this directory when rebuilding the datasets: a plain
`rm -rf data/bbbc020` destroys half an hour of work that no code can recreate.
A copy lives outside the repository at `../.weka_classifier_backup/`.
```

## Why it exists

1. **E4 part 2** asks students to load a classifier *someone else* trained and
   apply it to new images, so `bbbc020_cells.model` has to exist.
2. **Day 2** reads a pixel-classifier result back into Python to compare against
   Cellpose. Students who completed E4 use their own exports from
   `results/weka/`; these are the fallback for anyone whose Day 1 went awry.

## Regenerating the exports

The three pairs of TIFFs *can* be scripted, given the model:

```bash
fiji --headless --run .course/solutions/fiji/e4_weka_solution.groovy
```

That applies the classifier to the three fields and writes both outputs for each.

## Retraining the classifier

Only needed if the model is lost, or if the images change geometry: the feature
scales are in pixels, so a classifier trained on one framing does not transfer to
a different crop or resolution.

1. Open `data/bbbc020/images/15min_3_cells.tif` in Fiji.
2. `Plugins ▸ Segmentation ▸ Trainable Weka Segmentation`.
3. Two classes, `cell` and `background`. Add strokes, train, iterate: 
   concentrating on cell edges and the gaps between touching cells.
4. Check against `data/bbbc020/gt/15min_3_cells_labels.tif`. This field is the
   training image because its cell annotation is the most complete.
5. **Save classifier** here as `bbbc020_cells.model`.
6. Re-run the Groovy script above.

Then `pixi run fetch-data` to refresh `data/MANIFEST.md`.
