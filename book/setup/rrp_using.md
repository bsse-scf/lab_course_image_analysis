# Using the RRP

1. Open [rrp.ia-res.ethz.ch](https://rrp.ia-res.ethz.ch) and log in with your
   account. The credentials are handed out on Day 0.
2. Your project for the course is already created and listed under **Your
   projects**. It should also already be running; if its status is **not
   running**, click **▶** to start it.
3. Click **[↗]** to open JupyterLab.

In JupyterLab you find the course material in the `project` folder and the data
in `openbis`.

Some programs need a graphical desktop: Fiji, and the
[napari](https://napari.org/) viewer windows opened from the notebooks. To get
one, open a launcher (`File ▸ New Launcher`, or the **[+]** button above the
file browser) and click the **Desktop** icon, which starts a Linux desktop in a
new browser tab.
