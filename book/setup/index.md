# Setup

Four things, all of which should be done **before the first morning**. The
downloads are large and the lecture-room network is shared.

1. [Install Fiji](install_fiji.md) — for day 1
2. [Install Python](install_python.md) — pixi, git, and the repository
3. [Set up the environment](setup_environment.md) — one command, then check it works
4. [Download the example data](download_data.md) — for the day 2 challenge

If something goes wrong, bring it to the Day 0 session rather than fighting it
alone: install problems are far quicker to solve in person, and everyone hits
different ones.

```{note}
You need roughly **8 GB of free disk space** and a working internet connection.
The Python environment alone is around 3.5 GB, because it includes a deep
learning framework.
```
