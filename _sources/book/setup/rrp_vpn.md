# Accessing the RRP from outside ETH

Off campus, the RRP is only reachable through the ETH VPN. Install the VPN
client from [https://sslvpn.ethz.ch/](https://sslvpn.ethz.ch/).

```{warning}
You need slightly different settings and credentials from the ones you would
use normally (see below).
```

First, connect to the following URL:

![alt text](../illustrations/vpn_setting_2.png)

Then, use the following username ending together with

- your ETH network password (password)
- your two-factor-authentication password (second password)
