# Software installation and data download

The course uses Fiji, Python with JupyterLab, and a few example datasets. There
are two ways to get them:

- [Local computer](local.md): install everything on your own laptop. You need
  roughly 8 GB of free disk space and some time for the download.
- [Reproducible Research Platform](rrp.md): run everything in the browser on
  ETH servers. Nothing to install; you need the account credentials handed out
  on Day 0.
